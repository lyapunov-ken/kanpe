01FEATURES

言葉が、組版になる。

文字起こしをそのまま流すのではなく、キーワードだけを拾い、日本語の文字組みの作法で画面に置きます。

01
話す 美しい

漢字を立て、かなを引く

漢字は太く大きく、送りがなは約8割に縮めて細く。カタカナは字面が小さく見えるぶん少しだけ大きく。文字種ごとに組み分けます。

02
カンペカンペカンペ

繰り返すと、育つ

同じ言葉を話すたびに大きく、濃くなります。いま何が話題の中心なのかが、画面を見るだけで分かります。

03
新アイデア

初めての言葉に、小さなご褒美

その配信で初めて出た目立つ言葉だけ、アクセント色と下線で登場します。多用しないよう、5秒に1語までに絞っています。

04
えーっと、今日の話題

「えーっと」は出さない

えー、あのー、まあ、などのつなぎ言葉は画面にも文字起こしにも残しません。言い淀んでも、画面はすっきりしたまま。

05
余韻が残る

間があくと、余韻が残る

よく話すと画面は賑やかに、黙ると言葉はゆっくり薄れながら残ります。話のリズムに画面が呼吸を合わせます。

06
縦組字幕

縦組みも、字幕も

明朝テーマでは短い漢字語を縦に組んで、和のポスターのような構成に。最新の発話は文節で折り返す字幕ラインで出せます。

03BUSINESS

会議室でも、演台でも。

配信のためにつくったカンペは、仕事の場でも働きます。話した言葉がその場で見えると、会議は議論の中心がぶれにくく、講演は話の流れを見失いにくくなります。

BRAINSTORM

ブレスト会議は、出た言葉をみんなで眺める。

会議室のディスプレイに映しておくだけ。誰かが話すたびに言葉が画面に置かれ、ホワイトボードに書き出す手間なく、アイデアが場に並んでいきます。

  • 繰り返し出た言葉ほど大きく残るいま議論の中心が何かが、画面を見れば分かります
  • 初めて出た言葉はハイライトぽろっと出た小さなアイデアも拾い逃しません
  • そのまま議事録の下書きに終わったら文字起こしを TXT で保存できます
  • 社外秘は画面に出さないNG ワードに入れた名称は、画面にも字幕にも出しません

SPEECH

スピーチ・講演は、話した要点が手元に積み上がる。

演台や手元のモニターに、話し終えた要点が大きな文字で下から積み上がります。原稿を読み上げなくても、いまどこまで話したかが一目で分かります。

  • 話の現在地が分かる言い忘れや、同じ話の繰り返しを防ぎます
  • 会場のスクリーンに字幕を字幕ラインを映せば、後ろの席や聞き取りにくい方にも内容が届きます
  • 録画にはそのまま字幕をSRT を書き出して、講演動画の字幕に使えます
  • 固有名詞は登録しておく製品名や登壇者名を登録キーワードに入れると、優先して拾います

ほかにもウェビナー・オンライン研修・社内勉強会・朝会など、話す場面ならどこでも。コンソールの「ヘルプ」にある「シーン別の設定」から、ブレスト会議・スピーチ向けの表示にワンタップで切り替えられます。

06PRIVACY

話した言葉は、あなたの端末の中だけに。

KANPE には、文字起こしや設定を受け取るサーバーがありません。配信の内容を安心して扱えるよう、データの流れを最小限にしています。

  • LOCALサーバーに残さない

    文字起こし・設定・背景画像は、お使いのブラウザの中にだけ保存されます。KANPE が受け取ることも、保存することもありません。

  • BROWSER音声認識はブラウザの機能

    無料・お手軽プランの音声認識はブラウザに内蔵された機能です。音声はブラウザの提供元（Chrome は Google、Edge は Microsoft、Safari は Apple）が文字にし、KANPE には届きません。

  • DIRECT画面どうしは直接つながる

    コンソールと表示ビューは同じブラウザの中で直接やりとりし、OBS へは手元の OBS に直接つなぎます。OBS のパスワードがサーバーに送られることもありません。

  • ERASEいつでも消せる

    文字起こしは「消去」ボタンで、設定などはブラウザのサイトデータを削除すればすべて消えます。共用のパソコンでは、使い終わったら消去してください。

通信はすべて暗号化（https）されます。アプリの画面（コンソール・表示ビュー）には、広告や解析のタグ、外部のスクリプトを入れていません。この紹介ページと規約のページだけ、見られ方を知るために Google アナリティクスを使っています（話した内容が送られることはありません）。おトクプランのクラウド認識（近日公開）は、音声を認識のためだけに送り、KANPE のサーバーには保存しない設計です。

07FAQ

よくある質問

本当に無料で使えますか？

はい。無料版はブラウザに内蔵された音声認識とブラウザ内のキーワード抽出だけで動くため、利用料はかかりません。時間制限もありません。

どのブラウザで使えますか？スマホでも使えますか？

PC は Chrome と Edge、スマホは Android の Chrome と iPhone の Safari で音声入力が使えます。マイクの使用を許可してください。iPhone では「設定」で Siri（または音声入力）をオンにしておく必要があります。LINE や X などのアプリ内ブラウザでは使えないので、Safari か Chrome で開き直してください。表示ビューだけなら、OBS のブラウザソースを含めほとんどのブラウザで動きます。

OBS で使うにはどうすればいいですか？

認識は Chrome のコンソール画面で行い、結果を OBS に送ります。OBS の WebSocket サーバー機能（OBS 28 以降に標準搭載）を使えば透過で重ねられます。かんたんに試すなら、表示ビューの窓を OBS のウィンドウキャプチャで取り込む方法もあります。

話した内容はどこかに保存されますか？

KANPE のサーバーには何も保存されません。文字起こし・設定・背景画像は、お使いのブラウザの中（この端末）にだけ保存され、「消去」ボタンやブラウザのサイトデータ削除で消せます。音声を文字にする処理だけは、ブラウザの提供元のサービス（Chrome は Google、Edge は Microsoft、Safari は Apple）が行います。社外秘の内容を扱う場合は、NG ワードで画面と字幕に出さないようにできます。

会議や講演でも使えますか？

はい。会議室のディスプレイや演台のモニターに表示ビューを映して使えます。複数人の声も拾いますが、誰が話したかは自動では区別しません（話者の色分けは、ボタンかキーボードで切り替えます。お手軽プラン）。マイクから離れた席の声は拾いにくいので、話す人の近くにマイクを置いてください。機密性の高い会議では、社内のルールに沿って利用できるかご確認ください。

詳しい使い方はどこで見られますか？

コンソール右上の「ヘルプ」に、はじめかた・画面の見かた・シーン別のおすすめ設定・OBS の設定・うまくいかないときの対処をまとめています。使い方ガイドを開く

支払い方法と解約について教えてください

お支払いは Stripe の画面で、クレジットカードなどで行います（カード情報は KANPE を通りません）。月払いと年払いを選べ、自動で更新されます。解約はコンソール右上の「プラン」→「支払い方法・解約・領収書」からいつでもでき、解約後も期間の終わりまで使えます（日割りでの返金はありません）。別の端末で使うときや、ブラウザのデータを消したときは、ライセンスコードで復元できます。ライセンスコードはお申し込みの直後に画面に表示され、お申し込みのメールアドレスにも届きます。なくした場合は、コンソールの「プラン」→「ライセンスコードで復元」から、メールで送り直せます。

お手軽プランとおトクプランの違いは？

お手軽プラン（月¥480）は、VJ モードや話者の色分け、プレミアム書体、背景画像、カスタムロゴなど、見た目と演出の機能をまとめたプランです。音声認識はブラウザのものを時間無制限で使えます。おトクプラン（月¥2,980）は、それに加えてクラウドの高精度認識を月20時間ぶん含み、2時間の配信を週3回しても収まります。話している人の自動聞き分け、AI の要点抽出、配信後のサマリーも入ったぜんぶ入りです。
