縦組字幕

FAQ

よくある質問

本当に無料で使えますか？

はい。無料版はブラウザに内蔵された音声認識とブラウザ内のキーワード抽出だけで動くため、利用料はかかりません。時間制限もありません。

どのブラウザで使えますか？

Chrome と Edge を推奨しています。マイクの使用を許可してください。表示ビューだけなら、OBS のブラウザソースを含めほとんどのブラウザで動きます。

OBS で使うにはどうすればいいですか？

認識は Chrome のコンソール画面で行い、結果を OBS に送ります。OBS の WebSocket サーバー機能（OBS 28 以降に標準搭載）を使えば透過で重ねられます。かんたんに試すなら、表示ビューの窓を OBS のウィンドウキャプチャで取り込む方法もあります。

話した内容はどこかに保存されますか？

文字起こしはお使いのブラウザの中にだけ保存されます。KANPE のサーバーには送りません。ただし無料版の音声認識はブラウザ提供元のサービスを使います。社外秘の内容を扱う場合は、NG ワードの設定や Pro の利用をご検討ください。

Plus と Pro は何が違いますか？

Plus（月¥100）は書体や見た目など、使う人が増えても費用がかからない機能をまとめたプランです。Pro（月¥980）は、話した時間に応じて費用がかかるクラウドの高精度認識と AI の要点抽出を含みます。見た目だけなら Plus、精度も欲しいなら Pro を選んでください。
