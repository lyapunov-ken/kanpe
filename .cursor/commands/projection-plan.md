# 行事・講演の投影演出を企画する（projection-plan）

`docs/projection-research.md` を読んだうえで、ユーザーの行事（高校の式典挨拶／大学の講演会など）に合わせて次をまとめてください。

1. 話の要点（3つ程度）と、段階表示・現在地表示の構成
2. 聴衆参加の仕掛けを1〜2個（会場のネット・端末・校則に合わせて。ネットなしの代替も）
3. 節目だけに使う演出を1つ（締めの要点集約、拍手で反応など）
4. KANPE で実現する方法（`display.html` のレイアウト・テーマ・URL パラメータ、足りない機能は実装案）
5. 当日のリハーサル項目（マイク閾値、リモコン距離、投影の明るさ、オフライン時の代替）
