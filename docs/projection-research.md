# 高校の挨拶・大学の講演会の投影演出：調査メモ（2026-10-14）

Claude のチャットで行った調査の引き継ぎ用まとめ。KANPE を「要点ビジュアル」として行事・講演に使う企画や実装の前提にする。

## 結論
派手な演出より次の3つを軸にし、演出は「節目だけ」に絞る。
1. 要点を話の進行に合わせて1つずつ出す（段階表示＋現在地表示）
2. 聴衆に1〜2回だけ「答えさせる」（投票・ワードクラウド・匿名質問）
3. 最後に要点を1枚に集約して見せる

- 高校の式典挨拶：聴衆は参加しなくても要点が残る、静かな仕掛けを基本にする
- 大学の講演会：匿名質問・投票・コメントで双方向性を前面に出す

## エビデンスの要点
- クリッカー（ARS）のメタ分析（Hunsu ら 2016、53研究・2.6万人）：理解など認知面への効果は小さいが有意。意欲・関心など非認知面へはほぼ中程度。別のメタ分析（68研究）は認知 g=0.47、非認知 g=0.66
- 効くのは道具よりも「問いの設計」。遅延テストをした研究はなく、長期記憶への効果は未検証
- 能動的学習（Freeman ら 2014, PNAS）：試験成績 +0.47SD。授業時間の10〜15%だけ使う研究も含む → 数分の参加でも価値がある
- Mayer のマルチメディア原則：一貫性（無関係な素材を除く）23/23実験で支持、シグナリング（強調）24/28、冗長性（ナレーションに同じ文章を重ねない）16/16
- 誘惑的詳細（面白いが無関係な装飾）は成績を下げる：Rey 2012 で再生 d=−0.30、転移 d=−0.48。Cheng らは全体 g=−0.16、テクノロジー環境で g=−0.19
- → 「背景が動き続ける」「話の最中にコメントが流れ続ける」は誘惑的詳細になり得る

## 国内の実践
- 大学：CommentScreen（東大・稲見教授、京大・水原准教授の「ニコ動的講義」など）。東京電機大の評価研究（受講生92名）でコメント2,724件、ARCS 動機づけが向上（ただし小規模・非無作為）
- 高校：Mentimeter の匿名回答（北鎌倉女子学園）など授業での利用が中心。**全校集会・式典で生徒端末から投票して投影した報告は見つからなかった**
- 式典の投影演出：小禄高校（卒業式後に体育館の壁へプロジェクションマッピング）、鹿島学園高校（授業用プロジェクター＋PowerPoint のみで記念式典）

## アイデア一覧（★すぐできる／★★少し作り込み／★★★作り込みが必要）

### A. 高校の挨拶（3〜10分、体育館、数百人、スマホ不可が多い）
| 種類 | アイデア | 難易度 | 注意点 |
|---|---|---|---|
| 話し手 | キーワード段階表示（要点3つを話した瞬間に1語ずつ） | ★ | 文章を全部映さない（冗長性原則） |
| 話し手 | 「現在地」ドット ●○○ | ★ | あと少しで終わると分かり、集中が保てる |
| 話し手 | 話し手だけに見える残り時間 | ★ | スクリーンには出さない |
| 話し手 | 手元リモコン | ★ | 体育館の距離・予備電池 |
| 参加 | 端末なしで「心の中で選ぶ」問い（挙手でも可） | ★ | 最も現実的 |
| 参加 | 事前に HR で Forms 回収 → 挨拶でワードクラウドを1枚 | ★〜★★ | 自由記述は事前に目視確認 |
| 参加 | 始業式の目標ワードを終業式で振り返る | ★★ | 学期をまたぐ物語にできる |
| 参加 | 学年集会で学校配布端末から1問だけ投票 | ★★ | Wi-Fi・人数上限。小規模から |
| 演出 | 締めで3つのキーワードが中央に集まり1つのメッセージに | ★〜★★ | 最も費用対効果が高い。1回だけ |
| 演出 | 式典の後に思い出写真を投影 | ★★〜★★★ | 式辞中は不可。写真の同意範囲 |
| 演出 | 拍手の音量で花びら・光が広がる（Web Audio API） | ★★★ | 入学式・送る会など祝う場だけ |
| 演出 | 記念撮影用の背景画面 | ★ | カメラ映像は投影しない |

### B. 大学の講演会（60〜90分、受講者は端末あり）
| 種類 | アイデア | 難易度 | 注意点 |
|---|---|---|---|
| 話し手 | 目次＋現在地の常時表示、章の変わり目で目次に戻る | ★ | シグナリング |
| 話し手 | ペースタイマー（reveal.js の totalTime / data-timing） | ★ | 質疑を除いた時間で設定 |
| 話し手 | スマホでページ送り | ★ | USB リモコンも予備に |
| 話し手 | リアルタイム字幕・翻訳字幕（PowerPoint ライブ字幕） | ★ | 安定したネット必須。合理的配慮として価値大 |
| 話し手 | 音声認識で登録キーワードが出たら画面の語を光らせる | ★★★ | Web Speech API はサーバー処理が多くオフライン不可 → **KANPE の強みと直結** |
| 参加 | 冒頭の予想投票 → 最後に答え合わせ | ★ | 問いは事前に作る |
| 参加 | 匿名 Q&A＋いいね投票（Slido 等） | ★ | 承認制を有効に |
| 参加 | 流れるコメント | ★ | 質疑タイムだけ表示が無難 |
| 参加 | ワードクラウドの講演前後比較 | ★ | 講演の効果を全員で共有 |
| 参加 | QR コードで参加（冒頭・中盤・質疑前に表示） | ★ | 途中入場者のため |
| 演出 | 各章の要点カードが最後に1枚のマップへ集まる | ★〜★★ | 要約は「関連のある付加要素」なので積極的に |
| 演出 | 拍手・リアクション量のメーター | ★★〜★★★ | 区切りだけ。講演者評価に見せない |
| 演出 | 開演前・休憩・終演後だけ動くジェネラティブ背景 | ★★ | 本編中は静止 |

## 実装メモ
- 最小構成：PC＋プロジェクター＋HDMI＋プレゼン用リモコン
- reveal.js：フラグメント、スピーカービュー（S キー）、進捗バー。ライブラリはローカル同梱でオフライン可
- 拍手反応：`getUserMedia` → AnalyserNode で毎フレーム音量、閾値超えで描画。p5.sound の `getLevel()` でも可
- ネットなし会場：事前アンケート結果を画像で持ち込む／挙手・色カードを手入力で即グラフ化（ローカル HTML）／受信機型クリッカー
- 字幕：ネットなしなら端末内認識を事前検証するか要約筆記を手配

## 学校特有の配慮
- スマホ：文科省 2020/7/31 通知で高校は「原則校内使用制限」。公立高の8割超が校内使用を禁止（2019）→ 学校配布端末を使う
- 公立高の端末は約5割が保護者負担。故障も多い → 全員が端末を持つ前提にしない
- 投票ツールは匿名設定。海外クラウドへの保存は自治体ポリシーを確認。自由記述は承認制か事前確認
- 写真は同意範囲を確認。カメラ映像のリアルタイム投影は式典では避ける

## ツールの人数上限（2026年時点・変更の可能性あり）
- Slido 無料：100人・投票3つ/イベント。Teacher プラン 年12,000円で1,000人（代理店情報）
- Mentimeter 無料：アカウント全体で月50人
- Poll Everywhere 無料：1アクティビティ25回答
- Kahoot! 無料：50人
- → 全校規模は有料化か、学校契約の Microsoft Forms / Google フォーム

## 限界
- ARS 研究の大半は大学の授業。短い式典挨拶や単発の講演にそのまま当てはまるとは限らない
- 高校式典での双方向化は前例が乏しい。試すなら学年集会など小規模で、管理職の了承を得てから
- ベンダー発信の事例は宣伝的。「集中は20分が限度」などの通説は根拠にしない
